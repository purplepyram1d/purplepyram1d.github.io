SOC investigation

From a detection to an evidence-backed case

Wazuh brings together endpoint and application telemetry for alert search and detection engineering. Velociraptor supports targeted endpoint collections to test an investigation hypothesis. LabWatch connects source alerts to triage, evidence and case closure through direct Wazuh ingestion.

The public LabWatch snapshot presents selected resolved investigations, including the observations, troubleshooting and outcomes behind each case.

SRV01 applications and infrastructure

Protected services alongside a scoped practice range

Identity and files: DC01 provides Active Directory and DNS. Department groups and Group Policy support access to the Finance, HR and Radiology SMB shares on SRV01. Corp Documents uses IIS Windows Authentication, AD permissions and a Defender upload scanner.

Database integration: MySQL supplies application data. A directory worker reconciles the employee roster with AD identities for Corp Documents, combining database-backed application data with Windows authentication and group-based permissions.

Mail: hMailServer provides lab SMTP, submission, IMAP and POP3 services on SRV01. Mail authentication events are part of the detection exercises.

Practice: DVWA and BountyAPI support web and API exercises; BountyAPIFixed provides a comparison target for checking remediation. FakeCorp is an intentionally vulnerable portal with its own scope. Exercises use synthetic data and a defined scope to keep practice separate from the shared server’s operational services.

Networking and operations

Lab traffic, packet capture, and recovery

Network practice: Kali runs on ATTACKBOX for AD and application testing, with separate lab and NAT connectivity. A physical switch mirror port supports packet-capture exercises. Comparing physical and virtual traffic paths builds an understanding of where network evidence is visible and where it is not.

Operations: Scheduled health checks, telemetry monitoring and off-host backups support recovery practice. Recent work validated LabWatch ingestion after a lab shutdown and repaired an event-compatibility failure, using generated alerts and matching source events to confirm delivery. That work demonstrates troubleshooting across the event producer, detection engine, collector and case application.
